# Assets para a Chrome Web Store

- `desphila-store-icon-128.png`: ícone da loja, 128×128, PNG RGB sem transparência.
- `desphila-screenshot-1280x800.png`: captura promocional, 1280×800, PNG RGB sem transparência.

O campo de vídeo promocional é opcional. Se houver um vídeo publicado no YouTube,
informe a URL completa no formulário da loja; nenhum vídeo foi criado ou publicado
automaticamente por este projeto.
