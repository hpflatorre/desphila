# Segurança

## Relato responsável

Não publique cookies, tokens, URLs assinadas, relatórios nominais, capturas com
dados de estudantes ou outros dados pessoais em issues públicas.

Para uma vulnerabilidade sem dados pessoais, abra uma issue descrevendo o mínimo
necessário para reproduzir o problema. Se a evidência contiver segredo ou dado
sensível, use o recurso **Report a vulnerability** do GitHub, quando habilitado,
ou solicite ao mantenedor um canal privado sem anexar os dados à solicitação.

## Escopo conhecido

- O projeto não possui backend próprio nem telemetria.
- Dados coletados ficam no armazenamento local do perfil do Chrome.
- O pacote oficial deve conter apenas `manifest.json`, `INSTALLATION.md` e `src/`.
- A extensão depende das permissões e sessões dos sistemas institucionais.

## Versões

Enquanto o projeto estiver em versão `0.x`, somente a versão mais recente recebe
correções. O repositório não assume suporte institucional oficial.
